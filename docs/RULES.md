# 马尼拉 Manila — 规则规格书（引擎实现依据）

> 本文件是**唯一的规则真相来源**。引擎实现、测试、前端提示文案都以此为准。

## R1 准备（`createGame`）

- **R1.1** 3–5 名玩家，`config.players` 顺序即顺时针座次；`players[0]` 视为"最年长玩家"。玩家 id 依次为 `p1`…`pN`。每人 **30 比索**。
- **R1.2** 从 20 张股票中每种取 3 张（共 12 张）洗混，每人发 **2 张**（暗置，其他玩家看不到种类）。其余股票（每种 5 − 已发数量）放在版图旁作为 `shareSupply`。
- **R1.3** 同伙数量：3 人局每人 **4 个**；4、5 人局每人 **3 个**。
- **R1.4** 黑市四种货物价值全部为 **0**。
- **R1.5** 银行资金无限。
- **R1.6** 随机数（发股票、掷骰）只来自 `GameState.rng`（种子 `config.seed`），保证同种子 + 同动作序列 = 同结果。`config.debug.dice` / `config.debug.deal` 可覆盖（测试/演示用）。

## R2 航次流程

每个航次依次为：
1. **R3** 港务长竞拍
2. **R4** 港务长职责：买股票 → 装货与下水
3. **R5** 派遣同伙与移动货船（交替进行，含 **R6** 海盗、**R7** 领航员）
4. **R8.4–R8.5** 结算收益
5. **R9.1** 货物涨价；检查游戏结束 **R9**

## R3 港务长竞拍（phase `auction`）

- **R3.1** 第 1 航次由 `players[0]` 先叫价；之后每航次由**上一任港务长**先叫价。之后按顺时针轮流。
- **R3.2** 轮到的玩家要么**出价**（第一口 ≥ 1，之后必须 **严格高于** 当前最高价），要么**放弃**。放弃后本航次不能再参与竞拍。
- **R3.3** 出价上限 `maxBid` = 现金 + 12 × 未抵押股票数（即能凑出的钱）。
- **R3.4** 结束条件：只剩一名未放弃者且他是最高出价者 → 他当选，向银行支付出价（现金不足则按 R8.3 自动抵押）。若**所有人都放弃且无人出价**：上一任港务长连任且不付钱；第 1 航次则 `players[0]` 免费当选。【裁定】
- **R3.5** `pending = { type: 'bid', minBid, maxBid }`：`minBid` = 当前最高价 + 1（无人出价时为 1）。若 `maxBid < minBid`，该玩家只能放弃。

## R4 港务长职责（phase `harbor-master`）

- **R4.1 买股票（可选）**：港务长可从 `shareSupply` 买 **1 张**，价格 = max(5, 该货当前黑市价值)。供应为 0 的货不能买。现金不足时按 R8.3 自动抵押。只有港务长能买股票。
- **R4.2 装货**：港务长从 4 种货里选 3 种装上 3 艘船，剩下的 1 种留在岸上（`unloadedWare`）。
- **R4.3 下水**：每艘船放在不同航道上（动作数组下标 = 航道 0/1/2），起点在 **0–5** 格，三个起点之和 **必须恰好等于 9**。
- **R4.4** R4.2 与 R4.3 合并为一个动作 `load-punts`。

## R5 派遣同伙与移动（phase `placement` / `movement`）

- **R5.1 日程**：4、5 人局：派遣 → 移动 → 派遣 → 移动 → 派遣 → 移动；3 人局：派遣 → 派遣 → 移动 → 派遣 → 移动 → 派遣 → 移动（见 `VOYAGE_SCHEDULE`）。
- **R5.2 派遣轮**：每一轮从**港务长**开始顺时针，每名玩家放 1 个同伙到一个空位并支付该位价格，或**放弃**。放弃后本航次不能再派遣。已放弃或没有剩余同伙的玩家自动跳过。所有人都无法再派遣时，剩余派遣轮直接跳过（移动轮照常进行）。
- **R5.3 货船座位**：人参 1/2/3、肉豆蔻 2/3/4、丝绸 3/4/5、玉器 3/4/5/5（玉器 4 个座位）。玩家只选择"哪艘船"，引擎自动分配**最便宜的空座**。已经抵达港口的船不能再上人。
- **R5.4 其他位置**：
  - 港口 A/B/C：花费 4/3/2，若有船停在该泊位则得 6/8/15（银行支付）。
  - 船坞 A/B/C：花费 4/3/2，若有船停在该泊位则得 6/8/15（保险代理人支付，无代理人则银行支付）。
  - 海盗船 2 个位置，各花费 5：先到者是**船长**（captain），后到者是**船员**（crew）；同一玩家可占两个。
  - 领航员：小领航员花费 2，大领航员花费 5。
  - 港口/船坞泊位即使结果已确定（例如第 2 轮已有船停在港口 A）仍可派遣。【裁定：按规则原文"任何空位"】
- **R5.5 保险**：花费 0，派遣时**立即**从银行得到 10 比索（事件 `payout`，reason `insurance-premium`）。
- **R5.6 偷渡者（blind passenger）**：若玩家 现金 + 可抵押额度 < 所有空位（**不含保险**）中的最低价格，则 `pending.blindPassenger = true`：他可以把同伙放到**任意空位（保险除外）**，支付全部现金（可能为 0）而非标价。他仍可正常选择空着的保险位。
- **R5.7 移动轮**：`pending = { type: 'roll-dice' }`，由港务长掷骰。引擎为 3 艘船各掷一颗 d6，每艘船按自己货物的骰子前进。第 3 次移动之前先执行 **R7** 领航员。
- **R5.8 抵达**：船越过 13 格（位置 > 13）即抵达马尼拉，停入下一个空的港口泊位（A→B→C）。多余步数作废。同一移动步内多艘船抵达时按航道 0→2 顺序入泊。【裁定：收益只与抵达数量有关，顺序仅影响画面】
- **R5.9 搁浅**：第 3 次移动后仍在 0–12 格的船，按航道 0→2 顺序依次进入船坞 A→B→C。13 格上的船见 R6.3。

## R6 海盗（phase `pirates`）

- **R6.1** 只有**移动轮结束时**停在 13 格的船才会触发海盗；因领航员移动到 13 格的不触发。海盗船上没有人时不触发。
- **R6.2 登船（第 2 次移动后）**：对停在 13 格且有空座的船，**船长先决定**登上哪一艘（或留下），然后船员决定。登船者占据该船最便宜的空座、不付钱，此后算作该船的普通同伙（`seat.pirate = true`）。船长登船后，船员**立即晋升为船长**（事件 `pirate-promoted`）。船没有空座则不能登（变体 R10 除外）。
- **R6.3 劫掠（第 3 次移动后）**：停在 13 格的每艘船：
  - 若海盗船上有人：船上所有同伙（包括第 2 轮登船的海盗）被遣返且一无所获；海盗船上的人平分该货的利润（银行支付，向下取整，余数归船长）。然后**船长**为每艘被劫的船选择去港口还是船坞（`plunder-destination`）。去港口的货算作"抵达"，会涨价并触发港口泊位收益。
  - 若海盗船上没人：该船按抵达处理，进入下一个空港口泊位。【按英文规则书原文】
  - 顺序：先按 R5.9 把搁浅的船送进船坞，再处理 13 格上的船；船长按航道 0→2 顺序逐艘决定去向，送去船坞的船停在搁浅船之后的下一个空泊位。【裁定】

## R7 领航员（phase `pilots`）

- **R7.1** 在最后一次派遣轮结束后、第 3 次掷骰前执行。先小领航员，后大领航员；无人则跳过。所有船都已入港时跳过。
- **R7.2 小领航员**：把一艘尚未入港的船向前或向后移动 1 格，或不动。
- **R7.3 大领航员**：把一艘船移动 1 或 2 格，或把两艘**不同**的船各移动 1 格；方向各自决定；或不动。可以移动小领航员动过的船。
- **R7.4** 船不能退到 0 以下。被领航员推过 13 格的船立即抵达并入港（R5.8）。

## R8 资金、借贷与结算

- **R8.1 抵押**：任何时刻（游戏结束前）任何玩家都可以抵押一张未抵押的股票，从银行得到 12。
- **R8.2 赎回**：任何时刻付 15 给银行赎回一张抵押股票。竞拍进行中，**当前最高出价者**赎回后若 现金 + 12 × 未抵押股票数 < 自己的出价（赎回会让这个值少 3），则不能赎回，以免当选时付不起；其他玩家不受此限制。【裁定】
- **R8.3 强制借贷**：当必须付款（竞拍成交、买股票、派遣、保险赔付）而现金不足时，引擎**自动**依次抵押股票直到够付，优先抵押当前黑市价值最低的股票，同价按股票 id 顺序（事件 `loan-taken`，`forced: true`）。【裁定】
- **R8.4 收益结算**（第 3 次移动及所有海盗/领航员决定之后），顺序：
  1. 海盗劫掠收益（已在 R6.3 计算）；
  2. 抵达港口的船：船上同伙平分该货利润（人参 18、肉豆蔻 24、丝绸 30、玉器 36），银行支付，向下取整；
  3. 港口泊位：有船停靠且有同伙的泊位，该同伙得 6/8/15，银行支付；
  4. 船坞泊位：见 R8.5。
  - 进入船坞的船上的同伙一无所获。领航员本身不获得收益。
- **R8.5 保险赔付**：每有一艘船停入船坞泊位 X，保险代理人要支付该泊位的赔付额（A 6 / B 8 / C 15）：泊位上有同伙则付给该同伙，否则付给银行。代理人**先领取自己本航次的所有收益**再赔付；现金不足时按 R8.3 强制抵押；仍不足时由银行补足余额，代理人不需偿还。没有保险代理人时，船坞同伙由银行支付。

## R9 涨价与游戏结束

- **R9.1** 每航次结算后，本航次抵达港口（含被劫后送往港口）的每种货在黑市上涨一格：0→5→10→20→30。没抵达的不变。
- **R9.2 结束**：任一货物价值达到 **30** 时，本航次结束后游戏结束。每名玩家**财富** = 现金 + 所持**所有**股票的黑市价值（无论是否抵押）− 15 × 抵押股票数。
- **R9.3** 财富最高者获胜；平局则共享胜利。【裁定】
- **R9.4** 下一航次开始前：所有同伙回到玩家手中，船只、泊位、海盗、领航员、保险全部清空。

## R10 变体：强力海盗（`rules.pirateDisplace`，默认关闭）

海盗登船时若所有停在 13 格的船都没有空座，可以把一艘船上的一名同伙挤下去（遣返其主人），自己坐那个座位。必须优先填空座；第二名海盗不能挤掉刚登船的船长。

## 附：常见边界情况清单（引擎测试必须覆盖）

1. 3 人局 4 个派遣轮、4/5 人局 3 个派遣轮，移动轮始终 3 个。
2. 第 1 航次无人出价 → `players[0]` 免费当港务长。
3. 出价超过现金 → 当选时强制抵押。
4. 起点和 ≠ 9、起点 > 5、两船同航道、装同一种货 → `illegal-action`。
5. 船在第 2 次移动中抵达 → 第 3 次移动及领航员都不能影响它，也不能再上人。
6. 领航员把船推到 13 → 不触发海盗；推过 13 → 立即入港。
7. 第 2 轮后船长登船、船员晋升为船长；同一玩家占两个海盗位。
8. 第 3 轮后 13 格两艘船同时被劫 → 两份利润分别平分，船长分别决定去向。
9. 13 格的船在第 3 轮后、海盗船为空 → 进港。
10. 保险代理人自己在船坞有同伙 → 自己付给自己（净 0），事件仍要发出。
11. 保险代理人破产 → 抵押全部股票后银行补足。
12. 偷渡者：现金 0 且无可抵押股票时可免费上任意空位（保险除外）。
13. 买股票：供应为 0 的货不能买；价格最低 5。
14. 三种货同时到 30 / 某货已在 30 再次抵达 → 不超过 30。
15. 平局共享胜利。
16. 竞拍中最高出价者赎回股票后付不起自己的出价 → `insufficient-funds`，且不出现在合法动作里（R8.2）。
17. 第 3 轮后搁浅的船先占船坞泊位，被劫后送往船坞的船接在它们后面（R6.3）。
