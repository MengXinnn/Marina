# 美术方向：体素像素风（Voxel Pixel-Art）

- **低分辨率渲染 + 最近邻放大**：画布按 ~400 像素高渲染（`TARGET_PIXEL_HEIGHT`），CSS `image-rendering: pixelated` 放大，得到"3D 像素画"质感；UI 层保持清晰。
- **正交相机**：等距视角俯瞰海湾，可小幅旋转、缩放、平移。
- **体素模型全部程序化生成**（`scene/models.ts`），1 体素 = 0.1 单位（地形 0.25）。网格器（`scene/voxel.ts`）做面剔除 + 顶点 AO + 每体素轻微亮度抖动。
- **调色板唯一来源**：`scene/palette.ts`。货物色：人参黄、肉豆蔻棕、丝绸青、玉器绿；玩家色：红、蓝、橙、紫、白（刻意避开货物色）。
- **数字/字母**：3×5 像素字体直接"镶嵌"在体素上（航道格号、位置价格、收益牌）。
- **字体**：Fusion Pixel 12px（简体中文像素字体）+ Press Start 2P，全部本地打包（@fontsource），不依赖 Google Fonts（国内可用）。字号只用 12 / 24px。
- **UI**：硬边框像素面板、硬投影、无圆角无模糊。
- **地域特色（19 世纪马尼拉 / 东南亚港口）**：城区是西班牙殖民风格——火山凝灰岩（adobe）石墙、"石木楼"（bahay na bato：石砌底层 + 出挑木构上层 + 贝壳窗 capiz）、低坡红瓦四坡顶、双钟楼巴洛克教堂与广场喷泉、临海的圣地亚哥式炮台（西班牙旗）、拱廊海关（Aduana）。乡野是竹木高脚茅屋（bahay kubo）、香蕉树、竹丛、水牛、带舷外浮杆的螃蟹船（banca）。保险行是宾诺多（Binondo）华商店屋：红漆柱、绿琉璃瓦、红灯笼。地标模型在 `scene/landmarks.ts`。
- **地点识别**：港口 = 花岗岩条石码头（错缝铺砌、压顶石、木护舷）+ 泊位之间的木栈桥 + 货堆与路灯；修船厂 = 三条滑道 + 在建船体（船尾已铺板、船头露肋骨）+ 双坡茅草工棚 + 木料堆、焦油锅、备用锚；西侧码头 = 石砌货栈（门上四色货物遮阳棚）+ 木栈桥。**地面不要用两色交替的棋盘格**——那是"缺失贴图"的观感。
- 后续（M3）：描边后处理、粒子（水花、金币）、昼夜色调、音效。
